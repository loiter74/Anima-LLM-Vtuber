# 精修翻唱制作链

1. 在 `source/` 保存有使用权的歌曲工作副本，记录来源和工程采样率。
2. 分离主唱、伴奏及必要分轨到 `stems/`；主唱残留伴奏时先修复，不把串音送入 RVC。
3. 在 Melodyne 中只修正确定的音准和节奏问题，保留自然滑音、颤音和中文辅音时值。
4. 按呼吸、乐句和问题边界切分到 `phrases/`，每句登记 `production_jobs.csv`。
5. 使用已锁定的模型版本逐句 RVC，输出到 `converted/`；异常句单独调整，不覆盖首次结果。
6. 用 RX 处理爆音、齿音、水声、点击和呼吸残影，把处理说明写入句级记录。
7. 在 `sessions/` 完成 DAW 编辑、响度、空间、动态和伴奏融合；阶段导出到 `exports/`。
8. 交付前逐句回查歌词、相位、削波、噪声、响度和模型版本，并保留无母带与母带版本。

媒体、工程和导出均为本地产物，不提交到仓库。文件名使用稳定的 `phrase_id`，避免依赖 DAW
自动生成名称。建议保留 `dry vocal`、`RVC raw`、`RX repaired`、`mix` 四个可回退阶段。
