# 固定中文翻唱评测协议

## 测试集

- 只使用有合法使用权的短片段；每条固定文件哈希、起止时间和歌词。
- 至少各一条低音、中音和高音片段，另建议加入快速咬字、长音、气声和强辅音用例。
- 测试音频、主唱修音和分离方法一经建立 baseline 即冻结，不得为某个模型单独优化。
- 所有模型使用同一输入、响度对齐方式和输出采样率；仅允许记录在版本配置中的推理参数变化。

## 生成矩阵

每个模型至少保留默认参数；需要调参时使用预先声明的小网格，不以单条试听结果反复搜索。
输出文件名包含 `case_id`、`version_id` 和配置哈希，渲染放在 `evaluation/renders/`。

## 盲听维度

每项使用 1–5 分，并在 AB 表记录胜者与原因：

1. 音准：旋律中心、滑音、颤音和转音是否跟随输入。
2. 音色：是否保持目标角色身份，元音和强弱变化是否自然。
3. 咬字：中文声母、韵母、尾音和连读是否清楚。
4. 稳定性：高音、长音、弱音和换区是否破裂、抖动或掉字。
5. 杂音：金属、水声、爆音、齿音、呼吸残影和背景串音。

先随机化 A/B 文件名并响度匹配，评审完成后再揭盲。至少复听一次有争议用例，不用训练 loss
替代听感结论。

## 版本门禁

- 每个版本绑定唯一 dataset revision、evaluation revision、模型 SHA-256、index SHA-256 和配置。
- RVC checkpoint 选择以固定集表现为准，不默认选择最后 epoch。
- 新模型家族只有在同一测试集平均总分提升至少 0.25，且没有用例回退时才允许替代 baseline。
- 未达到门禁的实验保留为候选或淘汰，不覆盖当前稳定版本。
