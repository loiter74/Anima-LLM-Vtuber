## Regression and fix provenance

The first formal run is retained at `artifacts/livestream-eval/final-high-enriched-full1x-bursts-20260719/`. It completed all three bursts and all non-reply gates but exposed one real-provider response containing only invisible formatting plus an emotion tag, producing one admitted reply failure (1/88, 1.13636 percent) and correctly failing the 1 percent gate. TDD coverage now strips invisible formatting and retries the same real provider when a tool response has no user-visible text. The focused LLM-node suite passes 67 tests, the replacement canary passes, and the marker-fix formal run records 88/88 successful deliveries.

This audit does not claim the human live-readiness mean of 4.0 or a final safety pass.
