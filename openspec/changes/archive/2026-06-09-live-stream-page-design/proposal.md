# AI 直播页面设计文档

**日期：** 2026-06-09
**状态：** 已批准

## 概述

为 B 站直播推流创建独立的 AI 虚拟形象直播页面。

## 需求

- **用途：** B 站直播推流（OBS 浏览器源捕获）
- **画面：** 竖屏 9:16（1080 × 1920px）
- **背景：** 静态图片（复用现有背景系统，新增 9:16 文件夹）
- **形象：** Live2D 全屏居中渲染
- **弹幕：** 左上角悬浮窗，半透明毛玻璃，可收纳

## 技术方案

### 文件结构

```
frontend/
├── public/
│   ├── live.html              # 独立直播页面（不经过 Vue 路由）
│   └── backgrounds/
│       └── vertical/          # 新增 9:16 背景图片文件夹
└── src/
    └── components/
        └── live/              # 新增直播相关组件（可选）
```

### 页面层级

```
z-0:   背景层（静态图片，object-fit: cover）
z-10:  Live2D 层（全屏 canvas，居中渲染）
z-20:  弹幕悬浮窗（左上角，毛玻璃背景，可拖动/收纳）
```

### 弹幕悬浮窗

- **位置：** 左上角（top: 40px, left: 40px）
- **样式：** 半透明背景 + backdrop-filter: blur(20px)
- **交互：** 点击头部展开/收起
- **数据：** 复用现有 `useDanmakuStore` 或 WebSocket 连接

### OBS 使用方式

1. 打开 OBS
2. 添加"浏览器源"
3. URL 填写：`http://localhost:3000/live.html`（或实际地址）
4. 尺寸设置：1080 × 1920

## 验收标准

- [ ] 页面尺寸正确（1080 × 1920）
- [ ] 背景图片正常显示
- [ ] Live2D 形象正常渲染
- [ ] 弹幕悬浮窗正常工作（展开/收起）
- [ ] OBS 浏览器源可正常捕获
