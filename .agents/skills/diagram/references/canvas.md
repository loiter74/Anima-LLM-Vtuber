# Obsidian Canvas 规范

Canvas 用于自由布局场景——看板、空间化便签、头脑风暴白板。**结构化图不要用 Canvas,用 Mermaid。**

## 何时用 Canvas

- 看板 (To Do / In Progress / Done)
- 空间化便签 (自由摆放的卡片)
- 头脑风暴白板 (无固定结构)
- 需要手动空间编排的场景

**判据**: 如果图需要"自由摆放"而不是"自动布局",用 Canvas。否则用 Mermaid。

## 设计规范

### 节点尺寸规范 (最重要!)

**问题**: AI 往往写 `width=200, height=60`,导致文字被裁剪。

**解决**: 采用"大框策略",宁可留白,不允许文字溢出。

**尺寸计算规则**:

| 文本行数 | 最小宽度 | 最小高度 |
|---------|---------|---------|
| 1 行 | 250 | 80 |
| 2 行 | 280 | 120 |
| 3 行 | 320 | 160 |
| 4 行+ | 350 | 200 |

**按节点类型**:

| 节点类型 | 宽度 | 高度 |
|---------|------|------|
| 开始/结束 | 280 | 100 |
| 判断 | 260 | 100 |
| 普通步骤 | 320 | 140 |
| 多行步骤 | 320 | 160-200 |
| 侧栏/反应层 | 320 | 160 |

**公式估算**:

```
宽度 = max(280, 字符数 × 8)
高度 = 60 + 行数 × 40
```

**示例**:

```
文本: "**④ 执行**\nsmart-actions\nbridge.run()"
行数: 3
高度: 60 + 3×40 = 180
宽度: max(280, 30×8) = 280
```

**铁律**: 禁止统一使用 `width=200 height=60`。所有节点必须保证在 Obsidian Canvas 中无需手动调整即可完整显示。

### 颜色语义

| 语义 | 颜色代码 | 用途 |
|------|---------|------|
| 中性/复用 | 无色或 `""` | 现有模块,不变 |
| 扩展 | `"5"` (青) | 扩展现有模块 |
| 新建 | `"4"` (绿) | 新增模块/成功 |
| 删除/失败 | `"1"` (红) | 删除/失败 |
| 判断 | `"3"` (黄) | 分支判断 |
| 安全层 | `"6"` (紫) | 护栏/安全层 |

### 网格对齐

**铁律**: 同列共用一个 x,同行共用 y,行距统一。

```
列1 x=0    列2 x=300   列3 x=600
  │            │            │
  ▼            ▼            ▼
┌──────┐    ┌──────┐    ┌──────┐
│ y=0  │    │ y=0  │    │ y=0  │  ← 行1
└──────┘    └──────┘    └──────┘
┌──────┐    ┌──────┐    ┌──────┐
│ y=96 │    │ y=96 │    │ y=96 │  ← 行2
└──────┘    └──────┘    └──────┘
```

### 布局防重叠规则

**生成 Canvas 前必须进行 Layout Pass**:

1. **Group 宽度** >= 内部最大节点宽度 + 80px
2. **Group 高度** >= 内部节点总高度 + 80px
3. **Group 间距** >= 100px
4. **节点不得跨越 Group 边界**
5. **节点不得重叠**

**检查方法**:
```
∀ node_i, node_j: bounding_box(i) ∩ bounding_box(j) = ∅
```

**间距规范**:
- 水平间距: 300px
- 垂直间距: 120px
- Group Padding: 40px
- Node Margin: 30px

### 分组 (Group)

用 `group` 节点组织相关内容:

```json
{
  "id": "group1",
  "type": "group",
  "x": -20,
  "y": -20,
  "width": 540,
  "height": 300,
  "label": "**现有模块**",
  "color": "5"
}
```

**规则**: 分组内留 20px padding,分组标签用粗体。

## JSON 结构

```json
{
  "nodes": [
    {
      "id": "unique_id",
      "type": "text",
      "x": 0,
      "y": 0,
      "width": 240,
      "height": 64,
      "text": "**标题**\n简短描述",
      "color": "5"
    }
  ],
  "edges": [
    {
      "id": "edge_id",
      "fromNode": "node1",
      "fromSide": "bottom",
      "toNode": "node2",
      "toSide": "top",
      "label": "关系",
      "color": "4"
    }
  ]

```

### ID 生成

使用 16 位十六进制字符串:

```javascript
const id = Math.random().toString(16).slice(2, 18);
// 例如: "a3b2c1d0e9f8g7h6"
```

### 边 (Edge) 规范

| 属性 | 说明 |
|------|------|
| `fromSide` / `toSide` | `top` / `right` / `bottom` / `left` |
| `label` | 简短标签,≤5 字 |
| `color` | 与相关节点同色 |

## 常见错误

| 错误 | 后果 | 正确做法 |
|------|------|---------|
| 节点用 `## 标题` | 渲染成巨号字 | 用 `**粗体**` |
| 颜色随机 | 视觉噪声 | 固定 6 色语义 |
| 尺寸不一 | 列对不齐 | 同角色同尺寸 |
| 行距不统一 | 节奏不齐 | 统一 96px |
| 塞太多内容 | 节点撑爆 | ≤3 行,长内容拆笔记 |
| 结构化图用 Canvas | 手动摆位,容易乱 | 结构化图用 Mermaid |
