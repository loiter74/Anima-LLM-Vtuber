# Canvas 图示生成

## 规范

1. **节点标题用粗体，不用 `##`**
2. **同角色同尺寸**
3. **图和说明不分开**

## 颜色语义系统

生成前必须按语义划分颜色-功能，相同颜色不能挨着（除非功能一样）。

| 颜色 | 语义 | 用途 |
|------|------|------|
| **红 (1)** | 入口/失败/关键 | 开始节点、失败路径、待改造模块 |
| **橙 (2)** | 执行/动作 | 执行步骤、操作节点 |
| **黄 (3)** | 判断/分支 | 条件判断、分支节点 |
| **绿 (4)** | 成功/新建/完成 | 成功路径、新建模块、结束节点 |
| **青 (5)** | 流程/扩展/信息 | 流程步骤、扩展模块 |
| **紫 (6)** | 安全/护栏/工具 | 安全层、工具系统 |
| **无色** | 中性/复用 | 中性节点 |

**规则**:
- 入口必须用鲜明颜色（红/绿）
- 相邻节点不能同色（除非功能相同）
- 至少使用 3 种颜色

## 产出

```bash
python auto_resize.py input.canvas
```
