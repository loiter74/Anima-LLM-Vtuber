# 前端页面 vs 设计系统偏差记录

**生成时间**: 2026-06-20
**状态**: 待处理

## 1. 布局结构偏差

### 设计系统 (ui-kit.html)
```
┌────────────────────────────────────┐
│ Title Bar                          │
├──────┬─────────────┬───────────────┤
│ Left │   Center    │    Right      │
│ 280  │    1fr      │     340       │
│  px  │  (Live2D)   │      px       │
└──────┴─────────────┴───────────────┘
```

### 前端 (AppLayout.vue)
```
┌────────────────────────────────────┐
│ Title Bar                          │
├──────┬─────────────┬───────────────┤
│ Left │   Center    │    Right      │
│Float │   flex:1    │     380       │
│ able │  (Live2D)   │      px       │
└──────┴─────────────┴───────────────┘
```

**偏差**:
- 右侧面板宽度: 设计系统 340px vs 前端 380px (+40px)
- 左栏: 设计系统固定 vs 前端可折叠浮动

## 2. 左侧抽屉偏差

### 设计系统
- 固定侧边栏，始终可见
- 包含: Persona Card, Quick Controls, Memory List

### 前端
- 浮动可折叠抽屉 (LeftDrawer.vue)
- 可以隐藏/显示

**偏差**: 行为不同（固定 vs 可折叠）

## 3. 右侧面板偏差

### 设计系统
- 无 Tab 结构
- 直接显示记忆图谱面板

### 前端
- 6 个 Tab: 聊天/直播/记忆/人格/音乐/设置
- Tab 切换显示不同面板

**偏差**: 设计系统无 Tab，前端有 Tab

## 4. 记忆面板偏差

### 设计系统 (memory-graph-v2.html)
- 知识图谱可视化 (Canvas)
- 节点可拖拽、可点击
- 连线显示关系
- 筛选 + 搜索 + 列表

### 前端 (MemoryPanel.vue)
- 纯列表视图
- 筛选 + 搜索
- 无图谱可视化

**偏差**: 设计系统有知识图谱，前端只有列表

## 5. 样式系统偏差

### 设计系统
- CSS 变量: `var(--c-text)`, `var(--s-4)`, `var(--r-xl)`

### 前端
- UnoCSS: `text-c-text`, `px-5`, `rounded-xl`

**偏差**: 语法不同，但语义一致
