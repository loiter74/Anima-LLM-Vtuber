# Minecraft Bot Scripts

Manual Node.js scripts for exercising the Mineflayer bot outside the Python bridge.

| Directory | Purpose |
|---|---|
| `collect/` | Collection and movement smoke scripts |
| `craft/` | Focused crafting scripts |
| `workflows/` | Multi-step survival/crafting workflows |
| `debug/` | Debug repro scripts |
| `tests/` | Manual IPC and behavior test scripts |

The production bot entry point remains `../index.js`.
