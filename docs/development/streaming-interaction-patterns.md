# 直播互动模式（Streaming Interaction Patterns）

> 本文档梳理直播中常见的互动技巧与传播机制，供 Anima 直播互动模块参考。

## 1. 暗语/共谋式传播（Coded Language / Conspiracy Interaction）

主播与观众约定一个隐晦关键词（暗号），当触发时观众执行特定行为。刻意营造"别被发现"的氛围。

**核心机制**：
- 信息不对称 → 内群体/外群体划分
- 用"小声点"强化共谋感
- 听得懂 = 自己人，听不懂 = 外人（含网管）

**典型用途**：
- 引流：暗语引导去其他平台
- 绕审核：谐音/暗号聊敏感话题
- 付费门槛：舰长/房管专属信息

## 8. 自嘲式反讽（Self-deprecating Irony）

用骄傲/肯定的语气直接承认自己的失败。**褒义框架 × 贬义事实** → 认知失调 → 笑点。

### 核心公式
> 直接认菜 + 骄傲语气说出来

### 为什么有趣
1. **预期违背**：你以为他会懊恼，结果他自我表扬 → 意外
2. **降低威胁感**：自己先笑，攻击性归零
3. **情绪转化**：挫败感包进幽默壳里，观众不用替他难受
4. **隐性示强**：能自嘲 = 内心强大 = 好感度上升

### ❌ 伪自嘲（会让人生气的写法）
- "没我带节奏你们还真灭不了" — 甩锅队友
- "我跟地心引力很有缘" — 归因外因，像嘴硬
- "坠落感太真实了" — 美化失败

区分：真正的自嘲 = **直接承认自己菜**，不拐弯、不找借口、不推外因。

### 情绪走向（续写方向）

**起**：自嘲（平稳语气）→ **承**：递进 → **合**：落点决定效果

| 方向 | 例句 | 效果 |
|------|------|------|
| 自嘲升级 | "要不这游戏改成无限命算了，我一个人就能把全球配额用完" | 笑点更大 |
| 荒诞哲理 | "人嘛，命用光了才说明活过" | 一本正经胡说 |
| **突然破防** | "……我在想，另一个世界我们是不是可以做得更好，是不是可以更聪明？也许我们会 both win" | **反差萌 / 真实感** |
| 反转向好 | "但你们发现没有，我每次死的位置都特别有艺术感" | 硬找优点 |
| 甩给观众 | "有没有人统计一下我今天死了几次？我赌超过20" | 互动钩子 |

### 破防的本质

表面在自嘲（"真不愧是我"），说着说着**撑不住了**，真实情绪流出来。不是直白说"我好菜"，而是用一个"如果"包裹遗憾 → 底层是**不甘心**，不是在嘲笑自己，是真的想做好但做不到。比直白认输多了一层柔软，所以更打动人。

## 9. 底层逻辑

所有技巧的共性：**参与感 + 信息差 + 归属感**

```
观众心理：
"不看就亏了" → 留存
"我是自己人" → 归属
"我有影响力" → 参与
```

## 10. Anima 应用方向

### 10.1 弹幕模式识别
- 从弹幕流中检测互动模式触发（如特定关键词频率突增）
- 识别观众情绪周期（兴奋/疲劳/期待）

### 10.2 自动互动策略
- 根据直播间状态（人数、弹幕频率、礼物事件）自动选择互动模式
- 结合 Humor Skill 生成暗语/梗
- 弹幕分析 → 情绪判断 → 选择合适互动策略

### 10.3 与现有模块的集成
- `bilibili` service：弹幕接收与发送
- `memory`：记录直播间互动历史，学习有效模式
- `orchestration`：互动策略作为 graph node 集成到直播流程
