# Animetta Scope - 2026年7月

> 这次到底做什么，不做什么。项目失败很多时候不是因为做得少，而是因为 Scope 一直膨胀。

## 做（In Scope）

| 内容 | 理由 |
|------|------|
| 聊天场景 | 最基础的主播交互形式 |
| 本地闭环 | LLM→TTS→Live2D→前端 |
| 10分钟稳定运行 | 验证系统可用性 |
| 基础日志 | 排查问题必需 |
| 人设v0.1文档 | 确定主播基本形象 |
| 基础安全过滤 | 不乱答敏感内容 |
| 3条测试视频 | 可展示的Demo |

## 不做（Out of Scope）

| 内容 | 理由 |
|------|------|
| Minecraft | 场景复杂度过高 |
| 唱歌 | 需要额外音频处理 |
| 陪玩 | 需要游戏接入 |
| 直播平台正式接入 | 本地闭环未稳定 |
| 复杂长期记忆 | 优先级过低 |
| 多平台直播 | 分散精力 |
| UI美化 | 非核心需求 |
| 更多动作 | 非核心需求 |

## 验收标准

**7月底必须证明**：

- [ ] Anima 能本地连续跑 10 分钟
- [ ] 聊天场景成立（不是普通ChatGPT套皮）
- [ ] LLM → TTS → Live2D → 前端 哪一段最不稳已定位
- [ ] 能录制 10 分钟 demo
- [ ] 人设文档已确定

## Scope 膨胀预警

如果出现以下情况，立即检查 Scope：

1. 想做"顺便加个小功能"
2. 觉得"这个也挺重要的"
3. 开始研究"以后可能需要的东西"
4. 被新想法吸引

**应对**：问自己 "这个在7月Scope里吗？" 如果不在，放到 Backlog 或 Not Now。
